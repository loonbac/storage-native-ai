# Rechazadas

Ideas, estrategias o ramas descartadas, con el motivo. El objetivo es que pueda
reconstruirse la evolución intelectual del proyecto y que no se repitan callejones sin
salida.

Formato:

```text
IDEA — <título>
  Motivo de rechazo: <qué supuesto falló / por qué no se persigue>
  Evidencia: <referencia>
  Fecha:
  ¿Revisitable?: sí/no — <condición que la reactivaría>
```
